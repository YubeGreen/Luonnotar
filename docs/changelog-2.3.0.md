# 努昂诺塔 2.3.0

## 液态玻璃渲染器

- Android 13+ 新增基于 AGSL `RuntimeShader` 的光学玻璃路径。
- 使用圆角矩形 SDF 计算边缘法线，加入克制的背景折射、RGB 色散、Fresnel 边缘光、斜向镜面高光与触摸局部形变。
- 所有面板继续共享同一背景资源，不进行逐卡片截图。
- 新增共享低分辨率柔化采样图；玻璃主体从柔化源采样，折射边缘才使用清晰源，降低每像素采样成本。
- Android 12–12L 保留 `RenderEffect` 模糊路径；Android 8–11 使用共享柔化图降级，不再直接退化成纯色卡片。
- AGSL 创建或绘制失败时自动回退，不允许厂商着色器问题导致主界面崩溃。

## 材质与交互

- 光学模式下显著降低实体填充遮罩，背景不再只是“隔着一层半透明色”。
- 增加内外双层轮廓：左上高光、右下阴影与状态色仍保持可读。
- 触摸高光会同步驱动背景局部折射，同时保留原有轻微按压缩放。
- 调低图片背景的全局遮罩，使浅色和深色主题下的玻璃折射更容易看见。

## 性能边界

- 每块光学玻璃使用一个 `RuntimeShader`，但背景 Bitmap 与柔化 Bitmap 全局共享。
- 柔化采样图长边限制为 280–640 px，避免为每张卡片执行大半径实时高斯模糊。
- 完整光学效果仅在 API 33+ 启用，其余系统使用稳定降级路径。

## 研究参考

设计思路参考了 Android 官方 AGSL/RuntimeShader 文档，以及 AndroidLiquidGlassView、AndroidLiquidGlass、Liquid、Prismal 对“共享背景源 + 效果节点”、SDF 法线、折射、色散和 Fresnel 高光的公开实现说明。本版本着色器与 View 集成代码为针对努昂诺塔现有传统 View 架构重新编写的实现。
